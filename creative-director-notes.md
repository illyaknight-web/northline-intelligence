# NORTHLINE Creative Director V2

## Direction
The public site should behave like the NORTHLINE demo and executive pitch, not like a long-form brochure. The homepage is a cinematic front door. Deep content moves to dedicated pages.

## Homepage
1. Full-bleed education hero image + NORTHLINE proposition.
2. Four primary portal buttons: Family, Teacher, Principal, District.
3. Interactive demo preview / Principal Command Center.
4. Four large destination cards: Platform, Operations Intelligence, Evidence & Privacy, Knowledge Center.
5. Short Function Media / founder close.

## Dedicated pages
- platform.html — product architecture, school-day operating layer, interoperability.
- roles.html — Family, Teacher, Principal, District experiences.
- intelligence.html — transportation, attendance, communication, student services, safety, compliance, public source layer.
- evidence.html — stakeholder evidence, privacy, source provenance, FERPA / NY Ed Law 2-d framing.
- knowledge-center/ — existing editorial layer.

## Visual language
Use the demo/pitch language: role switching, command-center cards, operational timelines, drilldowns, strong buttons, restrained motion. Use real school/educator photography prominently. Do not imitate SAFEPLATE's food-system visual grammar. NORTHLINE remains navy / institutional blue / warm gold / paper.

## UX rule
No homepage section should feel like a report. The user should reach a meaningful destination within one click from the first viewport.
